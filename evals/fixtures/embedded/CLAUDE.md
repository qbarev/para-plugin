# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Two roots

- **`REPO_ROOT`** — this directory. Holds the tooling. **No note ever goes here.**
- **`PARA_ROOT`** — `REPO_ROOT/Second-brain`. Holds the vault proper.

`.claude/para/paths.md` is the full map; the roots it reads from `.claude/para/local/roots.md`.

## Skills — `.claude/skills/`

Skills that operate on this vault belong here, never in `~/.claude/skills/`.

Planning — «спланируй спринт», «распланируй день» — is not a skill: follow `todoist.md` «Rhythms».

Everything written to a note or printed to chat is in Russian; see `note-format.md`.
