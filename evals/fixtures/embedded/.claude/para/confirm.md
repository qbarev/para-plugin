# Confirming before acting

## Tier 1 — reversible: announce, then proceed

Creating a note, adding a Todoist task, archiving, moving.

## Tier 1.5 — input is missing: ask, then proceed

Ask the one question, take the answer, and continue.

**One named exception — planning.** The rhythms in `todoist.md` («Rhythms») set and
move dates and durations in Todoist. Show the whole proposal, wait for «да», then
write. A correction («СБ не надо, перенеси на ВТ») is a new proposal, not a yes.

## Tier 2 — irreversible: explicit yes, then proceed

Deleting anything, overwriting a file that already has content.
