# Thresholds

Every number the skills and the planning rhythms compute with.

## Sprint

| What | Value | Used by |
|---|---|---|
| Anchor — first day of sprint 1 | **2026-09-07** (a Monday) | `todoist.md` «Sprint» |
| Sprint length | **14 days** | same |
| Planned share of capacity | **80 %** | `todoist.md` «Capacity» |

## Capacity

The hours are in the note `Распорядок` under `Areas/`, section `## Ёмкость`. If the
note or the section is missing, say so and stop.

## Staleness

| What | Untouched for | Used by |
|---|---|---|
| A project has gone quiet | **14 days** | `/projects list` |
| An area has gone quiet | **60 days** | `/areas review` |

## Task counts

- **в спринте** — open tasks dated inside the current sprint;
- **просрочено** — open tasks dated before today;
- **в бэклоге** — open tasks with no date.
